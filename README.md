## 👩‍💻 Sobre mí

¡Hola! Senior en Ingeniera de software construyendo soluciones tecnológicas robustas, escalables y orientadas a resolver problemas reales.

🚀 A lo largo de mi carrera he trabajado desarrollando productos y sistemas que combinan calidad, rendimiento y una buena experiencia de usuario. Me motiva enfrentar nuevos retos y seguir evolucionando constantemente como profesional.

📊 Actualmente estoy ampliando mi perfil hacia el mundo de los datos, cursando un Máster en Big Data & Data Analytics, donde profundizo en el análisis, procesamiento y extracción de valor a partir de grandes volúmenes de información.

💻 Además, he complementado mi experiencia con un bootcamp Full Stack, reforzando mis habilidades tanto en frontend como en backend para construir aplicaciones completas de extremo a extremo.

### 🛠️ Tecnologías y herramientas

* Lenguajes: JavaScript / TypeScript / Python / Java
* Frameworks: React, Node.js, Spring Boot
* Herramientas: Git, GitHub, GitLab, Azure, MySQL, PostgreSQL, MongoDB, Scrum / Agile

### 🌱 Actualmente

* Integrando desarrollo de software con soluciones basadas en datos

### 🎯 Objetivos
